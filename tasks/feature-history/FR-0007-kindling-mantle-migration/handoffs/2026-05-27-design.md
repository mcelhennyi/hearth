# FR-0007 - Design handoff (2026-05-27)

## Executive summary

FR-0007 is registered for migrating Mantle ownership into Kindling. The design preserves Hearth as canonical host/deployment while making `@kindling/mantle` the compatibility dependency a standalone Kindling-based app uses to remain Hearth plugin-compliant.

## Suggested next step

Run `/identify-frontier`, then implement **Contract and transition docs** ([T-FR-0007-01](../tickets.md#t-fr-0007-01--contract-and-transition-docs)).

## Options

- **A.** Start with the docs ticket only, then move package source after the Kindling submodule is initialized in the feature worktree.
- **B.** If the Kindling repo is already ready in another checkout, staff **Move Mantle package source to Kindling** ([T-FR-0007-02](../tickets.md#t-fr-0007-02--move-mantle-package-source-to-kindling)) immediately after the docs ticket.
